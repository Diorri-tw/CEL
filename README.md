# CEL

**CEL** (**C**hip8-**E**mu-**L**earn) — учебный эмулятор CHIP-8 на C с подробными комментариями в коде. Рассчитан на тех, кто не писал на C и не знает, как устроен компьютер внутри.

> Я сам только учусь, поэтому в объяснениях и в коде могут быть ошибки. Но это даже хорошо, так как я максимально подробно распишу как я все понял. Поправки и вопросы — в заранее спасибо за правки! [Issues](https://github.com/Diorri-tw/CEL/issues).

## CHIP-8

**CHIP-8** — простая игровая система 1970-х (Pong, Tetris, Space Invaders). Эмулятор читает команды игры одну за другой и выполняет их так, как это делала бы настоящая система.

Для первого эмулятора она подходит идеально: 4 КБ памяти, 16 регистров, около 35 команд и экран 64×32.

## Запуск

Нужен компилятор C, например `gcc` из [MinGW-w64](https://www.mingw-w64.org/).

```bash
git clone https://github.com/Diorri-tw/CEL.git
cd CEL
gcc main.c -o main.exe
./main.exe
```

По умолчанию загружается `Pong.ch8`. Чтобы запустить другую игру, положи её `.ch8` в папку и поменяй имя файла в `main.c`.

> Пока только Windows: `windows.h` нужен для русского текста в консоли.
