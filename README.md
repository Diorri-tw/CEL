# CEL

**CEL** — это **C**hip8-**E**mu-**L**earn: изучаем CHIP-8, эмуляторы и язык C.

**Учим язык C и устройство эмуляторов — с нуля и простым языком.**

Это учебный проект. В нём я пишу эмулятор старой игровой системы **CHIP-8** на языке C и объясняю в комментариях почти каждую строчку: что она делает, зачем нужна и почему сделана именно так.

Объяснения рассчитаны на человека, который **никогда не писал на C** и не знает, как устроен компьютер внутри. Без заумных терминов, а если без термина не обойтись, он сразу объясняется.

Получается, что проект одновременно учит двум вещам:

- **языку C**: переменные, типы данных, массивы, структуры, указатели, функции, работа с файлами;
- **эмуляции**: как устроен процессор, что такое память, регистры, стек и таймеры, как программа «притворяется» другим компьютером.

---

## Что такое эмулятор и CHIP-8

**CHIP-8** — очень простая «игровая система» из 1970-х. На ней работали небольшие игры вроде Pong, Tetris и Space Invaders.

Игры для CHIP-8 — это набор команд для её процессора. Наш компьютер этих команд не понимает. **Эмулятор** — это программа, которая притворяется тем старым компьютером: читает команды игры одну за другой и делает то, что каждая из них означает. По сути, мы строим виртуальную приставку из кода.

CHIP-8 идеально подходит для первого эмулятора: у неё всего 4 КБ памяти, 16 регистров, около 35 команд и экран 64×32 точки. Её можно понять целиком, но при этом в ней есть всё то же самое, что и в «больших» системах.

## Как читать код

Весь код — в файле [`main.c`](main.c). Просто открой его и читай сверху вниз, как книгу.

- Всё, что после `//`, — комментарий. Компьютер его пропускает, он написан для тебя.
- К каждой строчке есть объяснение: **что** это, **зачем** и **почему** именно так.
- Короткие вопросы вроде «Зачем?» или «Почему?» — это ответы на то, что обычно приходит в голову по ходу чтения.

## Как запустить

Понадобится компилятор C. Проще всего на Windows поставить [MinGW-w64](https://www.mingw-w64.org/) (в нём есть `gcc`).

1. Скачай проект (зелёная кнопка **Code → Download ZIP**) или склонируй его:

   ```bash
   git clone https://github.com/Diorri-tw/CEL.git
   ```

2. Перейди в папку проекта и собери программу:

   ```bash
   gcc main.c -o main.exe
   ```

3. Запусти:

   ```bash
   ./main.exe
   ```

Файл игры `Pong.ch8` уже лежит в папке. Если хочешь попробовать другую игру, положи её `.ch8`-файл рядом с `main.exe` и поменяй имя файла в `main.c`.

> Сейчас проект работает только на Windows: он использует `windows.h`, чтобы русский текст в консоли отображался правильно.
